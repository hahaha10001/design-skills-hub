# Interface Compass Card

Use this card to compress a brief into design decisions.

```text
Audience:
Primary job:
Operating pressure:
Core artifact:
First-viewport promise:
Composition mode:
Density:
Voice:
Motion role:
Trust signals:
Non-goals:
Acceptance checks:
```

## Field Notes

- Audience: name the user's situation, not a demographic stereotype.
- Primary job: state the repeated action the interface must make easier.
- Operating pressure: identify what makes the task urgent, costly, emotional, or complex.
- Core artifact: dashboard, schedule, map, board, editor canvas, profile, quote, cart, document, model, report, or media object.
- First-viewport promise: what must be visibly useful without scrolling.
- Composition mode: choose one from `composition-modes.md` or name a more specific one.
- Density: spacious, balanced, dense, or instrument-like.
- Voice: terse, guided, calm, technical, editorial, operational, playful, or premium.
- Motion role: feedback, orientation, progress, continuity, delight, or none.
- Trust signals: evidence, constraints, provenance, timestamps, permissions, status, or explainability.
- Non-goals: patterns to avoid because they weaken this product.
- Acceptance checks: observable checks, not vague qualities.
