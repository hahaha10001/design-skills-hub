# Copy Patterns

## Buttons

- Save proposal
- Invite teammate
- Export CSV
- Retry payment
- Review changes

Avoid generic labels when the object is known.

## Empty States

```text
No proposals yet
Create the first proposal to track deadlines, notes, and client feedback in one place.
[New proposal]
```

Make the empty state explain the next useful action, not the whole product.

## Errors

```text
We could not save the proposal
Your connection dropped before the latest edits reached the server. Check your connection and try again.
[Try again]
```

Name what failed, explain why when known, and offer recovery.

## Success

```text
Proposal sent to Aster Studio
```

Prefer object-specific confirmation.

## Settings

Use plain descriptions:

```text
Email reminders
Send a reminder 24 hours before each proposal deadline.
```

Do not describe implementation mechanics unless the user needs them to decide.
