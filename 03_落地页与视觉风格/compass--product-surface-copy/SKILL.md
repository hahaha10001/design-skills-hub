# Product Surface Copy

## Goal

Make interface text useful under pressure. The copy should help users decide, act, recover, and trust what happened.

## Workflow

1. Identify the user's state: exploring, deciding, entering data, waiting, recovering, confirming, or managing.
2. Rewrite labels around the action or object, not internal implementation language.
3. Keep CTAs specific and short.
4. Pair errors with recovery steps.
5. Replace feature explanations with visible next actions in empty states.
6. Check text fit in buttons, tabs, badges, cards, sidebars, and mobile widths.

## Voice Rules

- Use concrete verbs.
- Prefer one clear sentence over a clever phrase.
- Remove hype unless the surface is explicitly marketing.
- Do not blame the user.
- Avoid vague success text like "Done" when the object can be named.
- Keep technical terms only when the audience expects them.

## Output Shape

When revising copy, return:

- Current issue.
- Replacement copy.
- Why it works.
- Layout risk, if the copy may overflow.
