# Implementation Checklist

Before finishing a reference-to-code task, check:

- The core layout proportions match the intended grammar.
- The first viewport contains the same kind of primary artifact or action.
- Typography hierarchy is visible at desktop and mobile sizes.
- Long labels and real data do not break controls.
- Image and media aspect ratios are stable.
- Components have hover, focus, loading, empty, and error states where relevant.
- No protected assets, exact copy, or third-party branding were reproduced without permission.
- The rendered result was inspected, ideally with screenshots.
