# Reference Analysis Template

Use this structure for each screenshot, mockup, or URL.

```text
Reference:
Purpose:
Viewport:
Primary artifact:
Layout skeleton:
Navigation:
Type hierarchy:
Spacing rhythm:
Color roles:
Component anatomy:
Media treatment:
Motion or interaction hints:
Transferable patterns:
Protected or unavailable specifics:
Implementation notes:
```

## Reading The Reference

- Describe geometry before style.
- Name what the user can do, not just what the screen looks like.
- Estimate density by content per viewport and control count.
- Identify what must remain stable across responsive sizes.
- Mark any asset that should be replaced or regenerated.
