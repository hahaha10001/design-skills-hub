# Token Starter

Use these categories as a practical minimum. Adapt names to the framework already in the repository.

## Color Roles

```text
surface/base
surface/raised
surface/sunken
surface/inverse
text/strong
text/default
text/muted
text/inverse
border/subtle
border/strong
action/primary
action/primary-hover
action/secondary
state/info
state/success
state/warning
state/danger
focus/ring
```

## Type Roles

```text
type/display
type/title
type/section
type/body
type/body-strong
type/caption
type/mono
```

Avoid viewport-width font sizing. Use breakpoint-specific tokens when type needs to change by screen size.

## Space Roles

```text
space/2xs
space/xs
space/s
space/m
space/l
space/xl
space/2xl
```

Use component-local gaps before adding many global spacing tokens.

## Shape And Depth

```text
radius/control
radius/panel
radius/dialog
shadow/raised
shadow/floating
border/width
```

Reserve large radius and deep shadow for components that truly float above the page.

## Motion Roles

```text
motion/fast
motion/base
motion/slow
ease/standard
ease/entrance
ease/exit
```

Always pair motion tokens with reduced-motion behavior.
