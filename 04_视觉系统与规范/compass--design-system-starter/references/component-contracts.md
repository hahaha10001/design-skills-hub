## Starter Components

Create only what the product uses in the next screen or flow.

- Button
- IconButton
- TextField
- Select
- Checkbox or Switch
- Tabs
- Dialog
- Toast
- Tooltip
- DataTable or List
- EmptyState
- StatusBadge

## Contract Rules

- Icon-only buttons need accessible labels and tooltips when the icon is not obvious.
- Repeated cards need fixed structural zones so content changes do not shift layout.
- Form controls need helper, error, disabled, and loading states.
- Tables need sort, empty, and overflow behavior before visual polish.
- Dialogs need focus trapping, escape behavior, and clear destructive-action handling.
